# 🎭 ASG Production — Frontend Application

Sisi Frontend Mobile & Web Application untuk **ASG Production - Sanggar Seni** dibangun menggunakan React Native Expo Router SDK 57 & TypeScript.

## Fitur Aplikasi
- 💬 **Obrolan Real-time WhatsApp-Style**
- 🎙️ **Voice Note Real (Rekam & Putar Audio)**
- 📍 **Berbagi Lokasi GPS Real ke Google Maps**
- 📷 **Upload Foto & Dokumen PDF**
- 📊 **Dashboard Job Admin & Tabel Riwayat Job Selesai**
- ✉️ **Alur Undangan Job Member (Accept / Reject)**
- 🔔 **Real Push Notifications**

## Cara Menjalankan
```bash
npm install
npx expo start --lan
```
